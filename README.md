# CastleEnvironment
Castle Environment – Unreal Engine 5
This project is a small castle environment created in Unreal Engine 5 to demonstrate level layout, composition, atmosphere, and visual clarity. I built the scene using terrain tools, starter and imported assets, materials, foliage, and lighting to create a cohesive and readable play space.

What I Worked On:
	Terrain sculpting + landscape painting.
	Placing and composing modular building assets.
	Setting up materials, clouds, lighting, and fog.
	Adding foliage for environment readability and realism.
	Creating visual flow and depth through lighting and composition.

This project strengthened my understanding of:
	How level layout guides player attention.
	How environmental cues support gameplay clarity.
	How terrains and environment create stories.
	UE5's world-building tools and workflows.

To view the project:
	Download the Unreal Engine project from the GitHub repository below.
	Open the project in Unreal Engine 5.
	Open the map: CastleEnvironment.umap
